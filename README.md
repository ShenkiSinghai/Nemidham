# नेमिधाम मंदिर वेबसाइट: बदलाव कैसे करें (आसान गाइड)

यह फ़ाइल सिर्फ़ एक काम के लिए है: **वेबसाइट पर कुछ बदलना, जोड़ना, हटाना या छुपाना।** कोडिंग आना ज़रूरी नहीं है।

> **यह Theme 2 (नया रूप) है:** गहरा बैंगनी + सुनहरा + क्रीम रंग, घूमता मंडल, उड़ती पंखुड़ियाँ, भामंडल में भगवान नेमिनाथ। पुराना रूप (Theme 1) अलग zip में सुरक्षित है। Theme 2 में दो CSS फ़ाइलें हैं, **`css/style.css` और `css/theme2.css` दोनों रिपॉज़िटरी में होनी चाहिए।** बदलाव का तरीका बिल्कुल पहले जैसा है (सब कुछ `js/data.js` से)। Theme 2 की नई चीज़ें भाग **5.22 से 5.28** में हैं।

**कैसे पढ़ें:** पहले भाग 1 और 2 एक बार पढ़ लो (5 मिनट). फिर जब भी कुछ बदलना हो, भाग 3 की तालिका में देखो कि वह कहाँ है, और भाग 5 में उसके स्टेप पढ़ो।

## 1. पहले ये 3 बातें समझ लो

1. **वेबसाइट की लगभग सारी जानकारी एक ही फ़ाइल में है: `js/data.js`.** समय, सूचना, कार्यक्रम, योजना, टीम, दान, फ़ोटो, सब इसी में है।
2. **हर लिखावट दो भाषाओं में होती है:** `hi` (हिंदी) और `en` (English). कुछ भी नया जोड़ो तो दोनों भरो।
   ```
   title: { hi: "यहाँ हिंदी", en: "Here English" }
   ```
3. **दो छोटे जादुई शब्द:**

| शब्द | क्या करता है |
|---|---|
| `hidden: true,` | उस चीज़ को वेबसाइट से **छुपा देता है** (मिटाता नहीं)। यह लाइन हटाओ तो चीज़ वापस दिखेगी। |
| `pinned: true,` | उस चीज़ को **Home पेज पर भी** दिखाता है (योजना, कार्यक्रम, सूचना के लिए)। लाइन हटाओ तो Home से हट जाएगी, अपने पेज पर बनी रहेगी। |

## 2. बदलाव करने का तरीका (हर बार यही)

### 2.1 सात स्टेप

1. **GitHub खोलो**, login करो, अपना रिपॉज़िटरी `Nemidham` खोलो।
2. फ़ोल्डर **`js`** → फ़ाइल **`data.js`** खोलो।
3. ऊपर दाईं तरफ़ **✏️ पेंसिल** दबाओ।
4. फ़ाइल के अंदर एक बार क्लिक करो, फिर **Ctrl + F** दबाकर वह नाम ढूँढो जो भाग 3 में बताया है (जैसे `window.EVENTS`). मोबाइल पर browser के मेन्यू में "Find in page" चुनो।
5. बदलाव करो (नीचे के नियम देखो)।
6. ऊपर दाईं तरफ़ हरा **"Commit changes..."** दबाओ, फिर दोबारा **"Commit changes"**.
7. **1-2 मिनट रुको**, वेबसाइट खोलकर **Ctrl + Shift + R** दबाओ (मोबाइल पर browser का cache साफ़ करो)।

### 2.2 लिखने के नियम (सबसे ज़रूरी)

- टेक्स्ट हमेशा **"दोहरे quote"** के अंदर रहे।
- हर चीज़ के आख़िर में **कॉमा ( , )** रहे।
- हर चीज़ `{ ... },` के **डिब्बे** में होती है। डिब्बा हमेशा **पूरा** कॉपी करो (`{` से `},` तक), आधा नहीं।

### 2.3 जोड़ना, हटाना, छुपाना: हर जगह एक ही तरीका

सूचना, कार्यक्रम, योजना, टीम का समूह, "हमारे बारे में" का हिस्सा, कैसे पहुँचें का डिब्बा, नियमित दान का कार्ड, गैलरी एलबम, कैलेंडर की तारीख़, सबमें:

- **नया जोड़ना:** उसी सूची का एक पूरा डिब्बा कॉपी करो, उसी के नीचे पेस्ट करो (दो डिब्बों के बीच कॉमा रहे), और टेक्स्ट बदलो। जिस डिब्बे में `id` है, उसकी `id` नई और अलग रखो (English छोटे अक्षर, बिना space).
- **हटाना:** पूरा डिब्बा मिटा दो।
- **कुछ समय के लिए छुपाना:** डिब्बे में `hidden: true,` जोड़ दो। फिर दिखाना हो तो वह लाइन मिटा दो।

**सबसे आम ग़लती:** कॉमा छूट जाना, quote बंद न होना, या डिब्बा आधा कॉपी होना। ऐसा हो जाए तो भाग 7 देखो।

| `js/i18n.js` | रिपॉज़िटरी → `js` | बटन, मेन्यू और पेज-शीर्षक के शब्द (भाग 5.19). |
| `js/main.js`, `css/style.css`, `css/theme2.css` | | वेबसाइट चलाने और डिज़ाइन का काम (रंग, अक्षर, चलती चीज़ें)। **इन्हें मत छेड़ो।** |

> अपना वेबसाइट का पता अलग हो (जैसे अपना डोमेन) तो ऊपर के पतों में `https://shenkisinghai.github.io/Nemidham` की जगह वही पता लगाओ।

> **जो `data.js` से नहीं बदलता:** मेन्यू के बाक़ी पेज (होम, योजनाएं, गैलरी आदि) कौन-कौन से हों, रंग, और कार्डों की बनावट। इनके लिए किसी जानकार की मदद लो। ("गतिविधियाँ" मेन्यू इसका अपवाद है: वह `window.ACTIVITIES` से अपने आप बनता है, भाग 5.20.)

**हर हिस्से के ऊपर `data.js` में `//` या `/* */` में छोटी हिदायतें भी लिखी हैं।** उन्हें भी एक बार पढ़ लेना।

## 4. फ़ोटो या फ़ाइल कैसे डालें

फ़ोटो, QR, लोगो जैसी फ़ाइलें `images` फ़ोल्डर में जाती हैं।

1. GitHub में रिपॉज़िटरी खोलो और सही फ़ोल्डर में जाओ (जैसे `images` या `images/team`).
2. ऊपर **Add file → Upload files** दबाओ।
3. फ़ोटो खींचकर (drag) वहाँ छोड़ दो।
4. नीचे **Commit changes** दबाओ।
5. फ़ाइल का **नाम** याद रखो (जैसे `ramesh.jpg`). यही नाम `data.js` में लिखना है।

> नाम छोटा, English अक्षरों में, बिना space का रखो: `ramesh.jpg`. "Ramesh ji photo 1.jpg" नहीं।

### ⚠️ फ़ोटो हमेशा पहले छोटी (resize) करके ही डालो

मोबाइल या कैमरे की फ़ोटो 3-8 MB की होती है। इतनी बड़ी फ़ोटो से GitHub पर upload में **error** आता है ("Commit failed", "file is too large", error 400) और वेबसाइट **धीमी** खुलती है।

**BIRME से छोटी करो** (`birme.net`, free, login नहीं चाहिए, एक साथ बहुत सारी फ़ोटो):
1. ब्राउज़र में `birme.net` खोलो।
2. सारी फ़ोटो एक साथ खींचकर वहाँ छोड़ दो।
3. **Width** में `1600` लिखो (Height खाली या auto), Quality `75` से `80`, format JPG.
4. **Save as Zip** दबाओ, zip को खोलो (unzip) और **अंदर की फ़ोटो** GitHub पर डालो।

इससे हर फ़ोटो लगभग 300-500 KB की रह जाती है और 50 फ़ोटो भी 15-25 MB में आ जाती हैं। (BIRME न खुले तो Windows में **PowerToys → "Resize pictures"** भी यही करता है।)

**GitHub पर डालते समय:**
- एक बार में **15-20 फ़ोटो** ही डालो, Commit करो, फिर अगली 15-20.
- एक फ़ाइल 25 MB से बड़ी न हो।

## 5. काम-दर-काम स्टेप

(हर काम में भाग 2.1 के स्टेप 1 से 4 पहले, और स्टेप 6-7 आख़िर में करने हैं। जोड़ने/हटाने/छुपाने का तरीका भाग 2.3 में है।)

### 5.1 नई सूचना (Announcement)

1. ढूँढो: `window.ANNOUNCEMENTS`
2. एक डिब्बा कॉपी करके नीचे पेस्ट करो। हर डिब्बा ऐसा है:
   ```
   {
     date: "2026-10-26", pinned: true,
     title: { hi: "...", en: "..." },
     text:  { hi: "...", en: "..." }
   },
   ```
3. `date` (साल-महीना-दिन), `title`, `text` बदलो (हिंदी और English).
4. **Home पर भी दिखाना है** तो `pinned: true`. सिर्फ़ सूचनाएँ पेज पर दिखाना है तो `pinned: false`.

### 5.2 नया कार्यक्रम (Karyakram)

1. ढूँढो: `window.EVENTS`
2. नीचे `hidden: true` वाला एक तैयार साँचा (template) है जिसमें "SAMPLE" लिखा है। उसकी `hidden: true,` लाइन हटाओ और टेक्स्ट बदलो। या किसी भी डिब्बे को कॉपी करो।

| लाइन | क्या लिखना है |
|---|---|
| `date: "2026-11-09"` | तारीख: साल-महीना-दिन |
| `endDate` | सिर्फ़ तब, जब कार्यक्रम कई दिन चले |
| `time` | समय, जैसे `{ hi: "सुबह 7:00", en: "7:00 AM" }` |
| `place`, `type` | जगह, और किस्म (उत्सव, पूजा...) |
| `title`, `text` | नाम और थोड़ी जानकारी |
| `pinned: true,` | Home पर भी दिखाने के लिए (अगले 3 आने वाले pinned कार्यक्रम दिखते हैं) |

पुराने कार्यक्रम अपने आप "पुराने" टैब में चले जाते हैं और 30 दिन बाद हट जाते हैं। दिन बदलने हों तो `window.SITE` में `karyakramPastDays` की संख्या बदलो (`-1` = कभी नहीं हटेंगे).

### 5.3 योजना (Yojana)

1. ढूँढो: `window.YOJANA`
2. एक डिब्बा कॉपी करके नीचे पेस्ट करो, **`id` नई रखो** (जैसे `"naya-kaam"`).

| लाइन | मतलब |
|---|---|
| `status` | `"active"` = प्रयास जारी है, `"soon"` = आगे आने वाली, `"done"` = पूरी हो गई |
| `title` | योजना का नाम |
| `short` | एक लाइन का विवरण (Home पर यही दिखता है) |
| `summary` | पूरा विवरण (योजना पेज पर) |
| `details` | बिंदुओं की सूची |
| `target` / `raised` | लक्ष्य और जमा राशि, जैसे `"₹ 11,00,000"`. न दिखानी हो तो `""` |
| `formUrl` | (वैकल्पिक) Google Form का लिंक। खाली `""` हो तो फ़ॉर्म का बटन नहीं दिखता। लिंक डालते ही उस कार्ड पर "अपनी रुचि दर्ज करें" बटन आ जाता है |
| `formText` | (वैकल्पिक) सिर्फ़ इस कार्ड के फ़ॉर्म बटन के अपने शब्द, `{ hi: "...", en: "..." }` |
| `photo` / `photos` | (वैकल्पिक) योजना की फ़ोटो (नक़्शा, ज़मीन, मॉडल)। एक: `photo: "images/yojana/sant-shala.jpg"`. कई: `photos: ["images/yojana/a.jpg", "images/yojana/b.jpg"]`. फ़ोटो पहले `images` में डालो (भाग 4, छोटी करके)। पहली फ़ोटो Home के कार्ड पर भी दिखती है; योजना पेज पर सारी दिखती हैं और दबाने पर बड़ी खुलती हैं। फ़ोटो न मिले तो वह अपने आप छुप जाती है |
| `pinned: true,` | Home पर भी दिखाने के लिए |

> पुराने कार्डों में हर कार्ड पर अलग "टीम पेज देखें" / दान बटन होता था। अब वह नहीं है, उसकी जगह पेज के ऊपर दो common बटन हैं। किसी कार्ड में पुरानी `link:` लाइन बची हो तो वह चुपचाप अनदेखी होती है, मिटा सकते हो।

**ख़ाली योजना कार्ड:** `window.YOJANA` में 4 छुपे हुए कार्ड "योजना 1" से "योजना 4" तक पहले से हैं। इस्तेमाल के लिए उसकी `hidden: true,` लाइन हटाओ और टेक्स्ट बदलो।

**योजना पेज के common बटन के शब्द बदलना:** योजना पेज पर ऊपर दो बटन एक ही बार दिखते हैं: "जानकारी के लिए संपर्क करें" (टीम पेज पर ले जाता है) और "योजनाओं के लिए दान करें" (दान पेज पर)। Google Form वाले बटन का शब्द भी सब कार्डों पर एक जैसा है। इन तीनों के शब्द बदलने के लिए `window.YOJANA_PAGE` ढूँढो और quote के अंदर लिखो:
```
window.YOJANA_PAGE = {
  contactText: { hi: "जानकारी के लिए संपर्क करें", en: "Contact us for details" },
  daanText:    { hi: "योजनाओं के लिए दान करें", en: "Give daan for the yojanayen" },
  formText:    { hi: "अपनी रुचि दर्ज करें", en: "Submit your interest" }
};
```
खाली `""` छोड़ोगे तो ऊपर वाले सामान्य शब्द चलेंगे।

### 5.4 Home पर क्या दिखे (Pin करना)

Home पर योजनाएँ, सूचनाएँ और कार्यक्रम, तीनों में **सिर्फ़ वही चीज़ें दिखती हैं जिनमें `pinned: true,` लिखा हो।**

- **Pin करना:** उसके डिब्बे में `{` के ठीक नीचे नई लाइन `pinned: true,` लिख दो।
- **Unpin करना:** वह लाइन मिटा दो। चीज़ अपने पेज पर बनी रहती है।
- अगर किसी हिस्से में कुछ भी pinned नहीं है, तो **वह पूरा हिस्सा Home से अपने आप ग़ायब** हो जाता है।
- कार्यक्रम में सिर्फ़ **आने वाले** pinned कार्यक्रम दिखते हैं (अगले 3). तारीख़ निकल जाए तो वह Home से अपने आप हट जाता है।
- अभी सारी 5 योजनाएँ, Welcome वाली सूचना और 9 नवंबर का कार्यक्रम pinned हैं। जो न चाहिए उनसे `pinned: true,` हटा दो।

### 5.5 मंदिर के समय (दर्शन, अभिषेक, आरती)

> **Home बैनर में समय की पट्टी:** चार समय एक रेखा और गोलों (dots) से जुड़े दिखते हैं। भरा हुआ गोला = समय निकल चुका, चमकता गोला + "अगला" = अब जो होने वाला है, खाली गोला = आगे का। इसमें कुछ अलग से भरना नहीं है, यह नीचे के समय से अपने आप बनता है।

1. ढूँढो: `timings:` (यह `window.SITE` में है)
2. चार समय **24 घंटे वाले रूप** में लिखो: सुबह 6:30 = `"06:30"`, शाम 7:30 = `"19:30"`.
   ```
   timings: { open: "06:30", abhishek: "07:30", aarti: "19:30", close: "21:00" },
   ```
3. समय के नीचे का नोट `timingsNote` में बदलो।
4. समय का डिब्बा पूरा छुपाना हो तो `showTimings: false`.

### 5.6 पता, फ़ोन, ईमेल, नक्शा

सब `window.SITE` में हैं:

| लाइन | क्या है |
|---|---|
| `addressLines` | पते की लाइनें |
| `phone` | फ़ोन नंबर, जैसे `"+91 98765 43210"` |
| `whatsapp` | WhatsApp चैट का नंबर, सिर्फ़ अंक, देश कोड के साथ: `"919876543210"` |
| `email` | ईमेल |
| `mapLink` | "Google Maps में खोलें" बटन का लिंक |
| `mapEmbed` | नक्शे वाला लिंक (Google Maps में Share → Embed a map, सिर्फ़ `src="..."` के अंदर वाला भाग) |

### 5.7 सोशल लिंक (WhatsApp, Facebook, Instagram, YouTube)

`window.LINKS` में चार लिंक हैं: `whatsappGroup`, `facebook`, `instagram`, `youtube`. हर लिंक quote के बीच पेस्ट करो। जिसका लिंक अभी नहीं है, उसे `""` रहने दो। उसका आइकन धुँधला दिखेगा और दबेगा नहीं।

### 5.8 ऊपर की सोने जैसी पट्टी (Banner)

`window.BANNER` में `text` (संदेश) और `link` (दबाने पर कौन सा पेज). हटानी हो तो `enabled: false`.

### 5.9 टीम में नाम जोड़ना

1. ढूँढो: `window.TEAM`
2. समूह के `members` में एक लाइन कॉपी करके नीचे पेस्ट करो:
   ```
   { name: "नाम", role: { hi: "पद", en: "Role" }, phone: "", photo: "" },
   ```
3. नाम, पद और फ़ोन बदलो। फ़ोन डालोगे तो दबाने पर कॉल लगेगा। न दिखाना हो तो `""`.
4. **फ़ोटो:** पहले फ़ोटो छोटी करके `images/team` में डालो (भाग 4), फिर `photo: "ramesh.jpg"` लिखो। फ़ोटो न हो तो नाम के अक्षर दिखते हैं।
5. नया समूह चाहिए तो पूरा `{ group: ..., members: [...] },` डिब्बा कॉपी करो।
6. **ट्रस्टी** वाला समूह अभी `hidden: true` से छुपा है। नाम तय होने पर वह लाइन हटा दो।
7. किसी एक व्यक्ति को हटाने के लिए उसकी पूरी लाइन मिटा दो।

### 5.10 दान की जानकारी (UPI, बैंक, QR)

> ⚠️ **यहाँ बहुत ध्यान रखो।** एक अंक की गलती से किसी का पैसा ग़लत जगह जा सकता है। बदलाव के बाद ट्रस्टी से दोबारा जँचवा लो।

ढूँढो: `window.DAAN`

| क्या | कैसे बदलें |
|---|---|
| पेज की शुरुआती लाइन, अतिरिक्त नोट | `intro`, `note` में (हिंदी और English) |
| UPI ID | `upiId: "..."` |
| QR फ़ोटो | नई QR फ़ोटो का नाम `upi-qr.png` रखकर `images` में अपलोड करो (भाग 4), पुरानी की जगह आ जाएगी |
| बैंक की जानकारी | `bank:` की हर पंक्ति `{ label: ..., value: "ICICI Bank" },` है। सिर्फ़ `value: "..."` बदलो। जिसमें `copy: true` है उसमें "Copy" बटन आता है (खाता संख्या, IFSC) |
| "मंदिर कार्यालय में" कार्ड | `inPerson` |
| पीली सावधानी लाइन | `disclaimer` (हटाना हो तो हिंदी और English दोनों `""`) |

कोई जानकारी खाली `""` छोड़ दो तो वह कार्ड अपने आप नहीं दिखता।

### 5.11 "नियमित दान और सेवा" के कार्ड

ढूँढो: `window.RECURRING`. हर कार्ड एक डिब्बा है:
```
{
  title: { hi: "...", en: "..." },   // कार्ड का बड़ा नाम
  when:  { hi: "हर महीने", en: "Every month" },   // ऊपर का छोटा टैग
  text:  { hi: "...", en: "..." },   // मुख्य विवरण
  how:   { hi: "...", en: "..." },   // नीचे की छोटी लाइन (कैसे जुड़ें / किससे बात करें)
  contacts: [ { name: { hi: "स्वप्निल जैन", en: "Swapnil Jain" }, phone: "" } ]   // वैकल्पिक
},
```
**संपर्क का नाम और नंबर:** `how` की लाइन में नाम लिख दो (जैसे "स्वप्निल जैन से संपर्क करें")। बाद में नंबर मिलने पर `contacts` में `phone: ""` के quote के अंदर नंबर लिख दो, कार्ड के नीचे "📞 नाम · नंबर" वाला बटन अपने आप आ जाएगा (दबाने पर कॉल लगता है)। जब तक `phone` खाली है, कुछ अलग नहीं दिखता। साप्ताहिक और मासिक शांतिधारा के कार्डों में भी यह जगह रखी है: नाम और नंबर लिखो, और चाहो तो `how` की लाइन भी बदल दो।
**मासिक भक्तामर भक्ति** का कार्ड भी यहीं है (हर महीने के दूसरे रविवार का पाठ). उसकी तालिका भाग 5.12 में है।
जोड़ना, हटाना, छुपाना: भाग 2.3. कार्ड उसी क्रम में दिखते हैं जिस क्रम में फ़ाइल में हैं।

**तैयार खाली कार्ड:** फ़ाइल में 3 छुपे हुए कार्ड "दान 1", "दान 2", "दान 3" पहले से हैं। इस्तेमाल के लिए उसकी `hidden: true,` लाइन हटाओ और अपना टेक्स्ट लिख दो।

### 5.12 पुण्यार्जक, द्रव्य दान और ट्रस्ट की जानकारी

- **`window.PUNYARJAK`** (शांतिधारा): हर नाम की एक पंक्ति `{ date, kind, name }`. `kind` में `"saptahik"` या `"masik"`. एक तारीख़ पर कई नाम हों तो हर नाम की अलग पंक्ति। अभी सिर्फ़ **चालू महीना** दिखता है। हर महीना दिखाना हो तो `window.SITE` में `punyarjakCurrentMonthOnly: false`.
- **`window.BHAKTAMBAR`** (भक्तामर पाठ, मासिक पुण्यार्जक): दान पेज पर **चालू साल के सारे 12 महीनों** की तालिका दिखती है, हर महीने के **दूसरे रविवार** की तारीख़ वेबसाइट अपने आप निकाल लेती है। जिस परिवार को जोड़ना है, उसकी एक पंक्ति: `{ month: "2026-11", name: { hi: "परिवार का नाम", en: "Family name" } },`। एक महीने में दो परिवार हों तो दो पंक्तियाँ। किसी महीने में पाठ दूसरे दिन हो तो पंक्ति में `date: "2026-11-15",` भी लिखो। जिस महीने में नाम नहीं है, वहाँ "अभी खाली है, आप नाम दे सकते हैं" दिखता है (बीते महीनों में "-"). किसी परिवार का नाम उसकी अनुमति से ही डालो। पंक्ति हटाने के लिए मिटा दो या `hidden: true`. पूरी तालिका हटानी हो तो `window.BHAKTAMBAR` का पूरा हिस्सा मिटा दो।
- **`window.DRAVYA`** (द्रव्य दान): `{ date, name }` की पंक्तियाँ। सूची खाली हो तो तालिका नहीं दिखती। किसी का नाम उसकी अनुमति से ही डालो।
- **`window.TRUST`** (ट्रस्ट / 80G): `items` की हर लाइन `{ label: ..., value: "" },` है। जो जानकारी है उसकी `value` में लिख दो, जैसे `value: "ABCDE1234F"`. **खाली `value` वाली लाइन नहीं दिखती**, और सब खाली हों तो "जानकारी जल्द जोड़ी जाएगी" दिखता है। नई लाइन के लिए एक लाइन कॉपी करके `label` और `value` बदलो। `note` में एक अतिरिक्त लाइन लिख सकते हो। पूरा हिस्सा हटाना हो तो `enabled: false`.

### 5.13 गैलरी: फ़ोटो एलबम और वीडियो एलबम

एलबम मतलब एक मौक़े की सारी फ़ोटो एक साथ (जैसे "दिवाली 2026"). हर एलबम की अपनी एक फ़ोल्डर होती है।

**स्टेप 1: फ़ोल्डर बनाओ और फ़ोटो डालो**
1. GitHub में `images` → `gallery` खोलो।
2. **Add file → Create new file** दबाओ। नाम वाले डिब्बे में लिखो `diwali-2026/ruko.txt` (`/` लिखते ही GitHub फ़ोल्डर बना देता है)। नीचे **Commit changes**. अब `diwali-2026` फ़ोल्डर बन गई।
3. **फ़ोटो पहले छोटी करो** (भाग 4).
4. उस नई फ़ोल्डर में जाओ, **Add file → Upload files**, और छोटी फ़ोटो डालो (एक बार में 15-20), Commit करो। बाक़ी फ़ोटो के लिए यही दोहराओ।
5. फ़ोटो के नाम `01.jpg`, `02.jpg` जैसे (English, बिना space).

**स्टेप 2: एलबम का टेक्स्ट बनवाओ (सहायक पेज से)**
1. वेबसाइट के पते के आख़िर में `/gallery-helper.html` लगाकर खोलो।
2. **Photo album** में भरो: नाम (हिंदी और English), छोटा नाम (जैसे `diwali-2026`), तारीख़, और फ़ोल्डर (`images/gallery/diwali-2026`).
3. चुनो: **"Photo ke naam likhwana"** (फ़ोटो चुनो तो नाम अपने आप भर जाते हैं) या **"Folder ki saari photo site khud dikhaye"** (नाम लिखने की ज़रूरत नहीं).
4. **"Lines banayein"** दबाओ और नीचे बना हुआ टेक्स्ट कॉपी करो।

**स्टेप 3: `data.js` में चिपकाओ**
`window.GALLERY` ढूँढो। उसमें `photos: [` के अंदर, पहले एलबम `{ ... }` के बाद **कॉमा** लगाकर कॉपी किया हुआ टेक्स्ट पेस्ट करो। Commit करो।

**बिना सहायक पेज के (हाथ से):** किसी एलबम का पूरा डिब्बा कॉपी करके नीचे पेस्ट करो और बदलो:

| लाइन | क्या बदलना है |
|---|---|
| `id` | एलबम का छोटा अलग नाम, बिना space, जैसे `"diwali-2026"` |
| `date`, `title` | तारीख़ (साल-महीना-दिन) और नाम (हिंदी, English) |
| `folder` | `"images/gallery/diwali-2026"` (बड़े-छोटे अक्षर फ़ोल्डर के नाम जैसे ही) |
| `files` | `["1.jpg", "2.jpg"]`. **यह लाइन पूरी हटा दो** तो साइट फ़ोल्डर की सारी फ़ोटो खुद दिखा देती है |
| `cover` | (वैकल्पिक) कवर फ़ोटो, जैसे `cover: "images/gallery/diwali-2026/05.jpg",` |

**कवर और फ़ोटो की गिनती:** `files:` लाइन न हो तो साइट फ़ोल्डर देखकर गिनती ("50 फ़ोटो") और कवर (फ़ोल्डर की **पहली फ़ोटो**) अपने आप लगा देती है (1 सेकंड लग सकता है)। कोई ख़ास फ़ोटो कवर चाहिए तो ऊपर की `cover` लाइन जोड़ दो।

**वीडियो एलबम:** `gallery-helper.html` के **Video album** वाले हिस्से में नाम भरो और हर लाइन में एक YouTube लिंक डालो (चाहो तो लिंक के बाद `|` लगाकर नाम). बना हुआ टेक्स्ट `window.GALLERY` के `videos: [` के अंदर पेस्ट करो। अकेला वीडियो, playlist या चैनल, तीनों के लिंक चलते हैं और वीडियो साइट के अंदर ही चलता है।

**वीडियो हाथ से जोड़ना:** `videos:` के किसी एलबम के `items: [ ... ]` में हर वीडियो की एक लाइन:
```
{ youtube: "https://www.youtube.com/watch?v=XXXXXXXXXXX", title: { hi: "शाम की आरती", en: "Evening Aarti" } },
```
छोटी वीडियो फ़ाइल (लगभग 25 MB तक) एलबम की फ़ोल्डर में डाली हो तो: `{ file: "video1.mp4", title: { hi: "...", en: "..." } }`. एलबम छुपाना हो तो उसके डिब्बे में `hidden: true,`.

**एलबम का क्रम:** गैलरी में एलबम हर एलबम की `date` के हिसाब से दिखते हैं। `window.SITE` में `albumOrder: "newest"` (सबसे नया पहले, अभी यही है) या `albumOrder: "oldest"` (सबसे पुराना पहले) लिखो। यह फ़ोटो और वीडियो दोनों एलबम पर लागू होता है। एलबम का `date` न हो तो वह सबसे नीचे जाता है।

**छुपाना:** एलबम (या किसी एक फ़ोटो/वीडियो) में `hidden: true,`.

### 5.14 Home की फ़ोटो पट्टी (स्लाइडशो)

`window.SITE` में `slideshow:` ढूँढो। लाइन ऐसी है:
```
slideshow: { enabled: true, source: "all", shuffle: false, count: 14, seconds: 2 },
```

| शब्द | क्या करता है |
|---|---|
| `enabled: true` / `false` | पूरी पट्टी चालू / बंद |
| `source: "all"` | सारे एलबम की फ़ोटो |
| `source: "kshamavani-2026"` | सिर्फ़ उस एक एलबम की फ़ोटो। यहाँ एलबम की `id` लिखो, बड़े-छोटे अक्षर वैसे ही |
| `shuffle: false` / `true` | हर बार एक ही क्रम / हर बार अलग क्रम |
| `count: 14` | कुल कितनी फ़ोटो आएँ (पहली 14, या `shuffle: true` हो तो सब में से चुनी हुई 14) |
| `count: "all"` | एलबम की **जितनी भी फ़ोटो हैं सारी** (संख्या अपने आप गिन लेता है) |
| `seconds: 2` | हर कितने सेकंड में आगे बढ़े (Theme 2 में 2). फ़ोटो पर माउस रखो (या मोबाइल पर उँगली दबाओ) तो पट्टी रुक जाती है, हटाओ तो फिर चल पड़ती है |

**उदाहरण: सिर्फ़ क्षमावाणी एलबम की सारी फ़ोटो एक-एक करके:**
```
slideshow: { enabled: true, source: "kshamavani-2026", shuffle: false, count: "all", seconds: 2 },
```

**स्लाइडशो धीमा लगे तो:** सबसे बड़ा कारण भारी फ़ोटो हैं (भाग 4). स्लाइडशो में फ़ोटो छोटी ही दिखती है, इसलिए फ़ोटो BIRME में **Width `1000` से `1200`** पर छोटी करके डालो (हर फ़ोटो 150-300 KB). `count: "all"` के साथ 50 भारी फ़ोटो एक साथ जुड़ती हैं, तो `count` कम रखो (जैसे `14`) और `shuffle: true` कर दो।

**ध्यान:** `"all"` में दोनों तरफ़ quote लगाओ। एलबम में फ़ोटो पहले अपलोड हो, वरना पट्टी खाली रहेगी या Home से हट जाएगी। अभी `images/gallery/vedi-pratishtha/` में 5 नमूने की फ़ोटो (`sample-1.jpg` से `sample-5.jpg`) रखी हैं। असली फ़ोटो डालने के बाद उस एलबम की `files:` लाइन और ये sample फ़ोटो हटा दो।

### 5.15 "हमारे बारे में" और "कैसे पहुँचें"

**हमारे बारे में** (`window.ABOUT`): दो हिस्से हैं:

| हिस्सा | पहचान (`id`) |
|---|---|
| मंदिर के बारे में | `"mandir"` |
| भगवान नेमिनाथ | `"bhagwan"` |

1. `window.ABOUT` ढूँढो और हिस्से को उसकी `id` से पहचानो।
2. `paragraphs: [ ... ]` में हर पैराग्राफ़ ऐसा है: `{ hi: "...", en: "..." },`. `hi` और `en` दोनों का टेक्स्ट बदलो।
3. हिस्से का नाम (शीर्षक): `title: { hi: "...", en: "..." }`.
4. नया पैराग्राफ़ जोड़ना या हटाना: भाग 2.3 जैसे (हिस्से के `paragraphs` के अंदर).
5. तीसरा हिस्सा चाहिए तो भाग 2.3 के हिसाब से पूरा हिस्सा कॉपी करो और `id` नई रखो। bullet points चाहिए तो हिस्से में `list: [ ... ]` जोड़ो।

**मंदिर के नियम** अब "दर्शन" पेज के चौथे टैब में हैं (भाग 5.25), "हमारे बारे में" में नहीं।

**कैसे पहुँचें** (`window.HOWTO`): यह "दर्शन" पेज के "कैसे पहुँचें" टैब में दिखता है। सबसे ऊपर अकेला **पता** का कार्ड (पता `window.SITE` → `addressLines` से), उसके नीचे नक्शा, फिर "कैसे पहुँचें - साधन" के नीचे सड़क / रेल / हवाई मार्ग / पार्किंग के डिब्बे, हर एक `{ title, text }`. `hi`/`en` बदलो। पार्किंग वाला अभी `hidden: true` से छुपा है, दिखाना हो तो वह लाइन मिटा दो। फ़ोन और नक्शे का लिंक `window.SITE` में हैं (भाग 5.6).

### 5.16 जैन कैलेंडर (पर्व, कल्याणक, तिथि)

`window.CALENDAR` में हर तारीख़ एक डिब्बा है:

| लाइन | क्या लिखना है |
|---|---|
| `date` | तारीख़: साल-महीना-दिन |
| `type` | `"kalyanak"`, `"parv"`, `"tithi"` या `"other"` |

तारीख़ें किसी भरोसेमंद पंचांग से देखकर लिखो। अभी इसमें "SAMPLE" वाली तारीख़ें हैं, उन्हें असली से बदल दो या `hidden: true,` से छुपा दो।

### 5.17 नाम, एक लाइन का परिचय, लोगो, बड़ी फ़ोटो, "वेबसाइट संयोजक"

`window.SITE` में:
- **`name`, `place`:** मंदिर का नाम और जगह। नाम बदलो तो हर `.html` फ़ाइल के ऊपर की `<title>` वाली लाइन भी बदलो (Google और ब्राउज़र टैब वही पढ़ते हैं)।
- **`tagline`:** छोटा परिचय (Google/साझा करने पर)। **Home के बैनर की लाइन अब `heroLine` है** (भाग 5.22).
- **`heroImage`:** (वैकल्पिक) Home के ऊपर पीछे की बड़ी फ़ोटो, जैसे `"images/hero.jpg"`. न चाहिए तो `""`.
- **`credit`:** फुटर का "वेबसाइट संयोजक": `credit: { name: "...", url: "..." }`. हटाना हो तो `credit: null`.

**लोगो बदलना:** नया लोगो वर्गाकार (square) PNG हो, जिसमें गोल निशान पूरा भरा हो और कोने पारदर्शी हों। उसका नाम `mandir-logo.png` रखकर `images` में अपलोड करो (भाग 4), पुरानी की जगह आ जाएगी। ब्राउज़र टैब के छोटे आइकन अलग फ़ाइलें हैं (`favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`), लोगो बदलो तो इन्हें भी बदलो।

| `analyticsId` | Google Analytics की ID। निजी आँकड़े (सिर्फ़ आपको) analytics.google.com पर दिखते हैं |
| `youtubeChannelId` | (वैकल्पिक) आपके YouTube चैनल की ID (`UC` से शुरू). भरने पर चैनल के सारे वीडियो गैलरी में चलते हैं और नए वीडियो अपने आप जुड़ जाते हैं। YouTube Studio → Settings → Channel → Advanced में मिलती है |
| `mapQuery` | (वैकल्पिक) जगह का नाम या coordinates। `mapEmbed` और `mapLink` पहले से भरे हैं, इसे छोड़ सकते हो |
| `github: { user, repo }` | आपका GitHub नाम और रिपॉज़िटरी का नाम। गैलरी की फ़ोटो अपने आप दिखाने के लिए ज़रूरी है। **रिपॉज़िटरी का नाम न बदला हो तो इसे मत बदलना** |
| `timezone` | भारत के लिए `"Asia/Kolkata"` ही रहने दो |

### 5.19 पेज के शीर्षक, मेन्यू और बटन के शब्द (`i18n.js`)

हर पेज के ऊपर का शीर्षक और उसके नीचे की एक लाइन, मेन्यू के नाम, बटन के शब्द और Home के दो नीचे वाले कार्ड का टेक्स्ट **`data.js` में नहीं, `js/i18n.js` में** हैं।

**स्टेप:**
1. GitHub में `js` → `i18n.js` खोलो → पेंसिल ✏️.
2. Ctrl + F से वह शब्द ढूँढो जो वेबसाइट पर दिखता है (जैसे `मंदिर के आने वाले काम`). फ़ाइल में वह **दो बार** मिलेगा: हिंदी वाले हिस्से में और English वाले हिस्से में।
3. quote के अंदर का टेक्स्ट बदलो, **दोनों भाषाओं में**. quote और कॉमा जैसे हैं वैसे रहने दो। लाइन में `{n}` जैसा कुछ हो तो उसे मत छेड़ो (वहाँ वेबसाइट अपने आप संख्या डालती है)।

| यह बदलना है | ढूँढने का नाम |
|---|---|
| किसी पेज का शीर्षक / नीचे की लाइन | `p.yojana.h1` / `p.yojana.lead` (योजना की जगह `karyakram`, `calendar`, `announcements`, `gallery`, `about`, `team`, `daan`, `visit`) |
| मेन्यू के नाम | `nav.` से शुरू होने वाली लाइनें ("गतिविधियाँ" मेन्यू का नाम `nav.activities`; जैसे "समुदाय" या "नेमिधाम परिवार" करना हो तो यहाँ बदलो) |
| Home के दान और "कैसे पहुँचें" के कार्ड | `home.daan_h`, `home.daan_p`, `home.daan_btn`, `home.visit_h`, `home.visit_p`, `home.visit_btn` |
| "जल्द आ रहा है" निशान और गतिविधियाँ पेज के संदेश | `act.soon`, `act.soon_text`, `act.none`, `act.contact_h`, `act.poster_hint` |
| योजना पेज के common बटन के शब्द | पहले `window.YOJANA_PAGE` (भाग 5.3), वहाँ खाली हो तो `y.common_contact`, `y.common_daan`, `y.form` |
| भाषा बदलने का बटन | `lang.btn` (कंप्यूटर पर), `lang.short` (मोबाइल पर छोटा नाम) |
| Home के हिस्सों के शीर्षक और "सब देखें" | `home.yojana`, `home.notices`, `home.events`, `home.photos`, `home.yojana_all` आदि |

### 5.20 गतिविधियाँ मेन्यू (क्रिकेट क्लब, ट्रेकिंग, यात्रा संघ, किड्स क्लब)

ऊपर के मेन्यू में **"गतिविधियाँ"** नाम का हिस्सा है। उसके अंदर हर गतिविधि का नाम दिखता है, और हर गतिविधि का **अपना अलग पेज** है (`kids-club.html`, `trekking.html`, `cricket-club.html`, `tirth-yatra.html` (नाम "यात्रा संघ")). "गतिविधियाँ" पर दबाने से कोई अलग पेज नहीं खुलता, सिर्फ़ नीचे नाम खुलते हैं। पेज का सारा टेक्स्ट **`window.ACTIVITIES`** में है।

**पोस्टर कैसे लगाएँ:**
1. पोस्टर की फ़ोटो पहले छोटी करो (भाग 4, BIRME पर Width `1000` या `1200`).
2. GitHub में `images` → `activities` फ़ोल्डर खोलो → **Add file → Upload files** → फ़ोटो डालो → Commit.
3. `data.js` में उस गतिविधि के डिब्बे में लिखो: `poster: "images/activities/kids-club.jpg",` (अपनी फ़ोटो का नाम)।
4. पेज पर पोस्टर बायीं तरफ़ दिखेगा और दबाने पर पूरा बड़ा खुलेगा। पोस्टर न चाहिए तो `poster: ""`.

**पेज की जानकारी भरना** (सब वैकल्पिक है। जो लाइन खाली हो या हटा दो, वह हिस्सा पेज पर दिखता ही नहीं):

| लाइन | मतलब |
|---|---|
| `id` | छोटा नाम, English छोटे अक्षर, बिना space। एक बार रखकर बदलना मत |
| `page` | उस गतिविधि के पेज की फ़ाइल का नाम, जैसे `"kids-club.html"` |
| `comingSoon` | `true` = "जल्द आ रहा है" निशान, `false` = निशान नहीं (पेज तैयार होने पर `false` करो) |
| `title` | मेन्यू और पेज का नाम (हिंदी, English) |
| `short` | पेज के शीर्षक के नीचे की एक लाइन |
| `poster` | पोस्टर की फ़ोटो का रास्ता (ऊपर देखो) |
| `decor` | पेज के ऊपर बड़े उछलते emoji, जैसे `decor: "🎈 ⚽ 🎨 📚",` (emoji के बीच space)। न चाहिए तो `""` |
| `banner` | एक चमकती नारे वाली लाइन, `{ hi: "...", en: "..." }` |
| `info` | छोटी मुख्य जानकारी (कब, कहाँ, सीटें, फ़ीस...)। हर एक: `{ icon: "📅", label: { hi: "कब", en: "When" }, value: { hi: "हर शनिवार शाम", en: "Every Saturday evening" } },` (`icon` एक emoji) |
| `paragraphs` | सादा टेक्स्ट। हर अनुच्छेद: `{ hi: "...", en: "..." },` |
| `list` | बिंदुओं की सूची, `{ hi: "...", en: "..." },` की तरह |
| `sections` | शीर्षक वाले रंगीन डिब्बे। हर एक: `{ icon: "🎮", color: "blue", title: { hi: "...", en: "..." }, sub: { hi: "...", en: "..." }, list: [ {hi,en}, {hi,en} ] },`। `color` में से एक: `orange`, `blue`, `purple`, `green`, `pink`, `gold`, `teal`. `sub` = शीर्षक के नीचे की छोटी लाइन (वैकल्पिक). पूरी चौड़ाई का डिब्बा चाहिए तो `wide: true,`. `paragraphs: [ ... ]` भी लिख सकते हो |
| सूची की हर लाइन में emoji और समय | `{ icon: "🥾", time: { hi: "सुबह 7:15 – 8:30", en: "7:15 – 8:30 AM" }, hi: "...", en: "..." },` (`icon` और `time` वैकल्पिक हैं। समय हो तो रंगीन गोली में दिखता है) |
| `contacts` | किसे फ़ोन करें। हर एक: `{ name: { hi: "सौरभ जैन", en: "Saurabh Jain" }, role: { hi: "संयोजक", en: "Coordinator" }, phone: "7987070139" },` (`role` वैकल्पिक है)। फ़ोन पर दबाने से कॉल लगता है |
| `contactTitle` | संपर्क वाले डिब्बे का शीर्षक, `{ hi: "जुड़ें हमारे साथ!", en: "Join us!" }`. न लिखो तो "संपर्क करें" |
| `contactNote` | संपर्क वाले डिब्बे की ऊपर की एक लाइन |
| `formUrl` | (वैकल्पिक) Google Form का लिंक। quote के अंदर डालते ही "अपनी रुचि दर्ज करें" बटन आ जाता है। बटन के शब्द बदलने हों तो `formText: { hi: "...", en: "..." },` लिखो |

`contacts` खाली हो तो संपर्क वाले डिब्बे में "जानकारी के लिए संपर्क करें" बटन आता है जो टीम पेज पर ले जाता है।

**पेज के कार्ड और जानकारी: जोड़ना, हटाना, छुपाना (चारों गतिविधि पेज पर एक जैसा):**

| क्या करना है | कैसे |
|---|---|
| कोई कार्ड (`sections` का डिब्बा), जानकारी की पंक्ति (`info`), संपर्क वाला व्यक्ति, सूची की एक लाइन या अनुच्छेद **छुपाना** | उसमें `hidden: true,` लिख दो। चालू करना हो तो वह शब्द मिटा दो |
| उनमें से कुछ **हटाना** | उसकी पूरी `{ ... },` लाइन या डिब्बा मिटा दो |
| **नया कार्ड जोड़ना** | हर गतिविधि में छुपे हुए "नया कार्ड" पहले से रखे हैं। उसमें से `hidden: true,` मिटाओ और टेक्स्ट बदलो। और चाहिए तो किसी पूरे `{ ... },` डिब्बे को कॉपी करके उसके नीचे पेस्ट करो |
| नई जानकारी की पंक्ति / नया संपर्क जोड़ना | वैसे ही: छुपी हुई "नई जानकारी" / "नाम" वाली पंक्ति से `hidden: true,` मिटाओ, या कोई पंक्ति कॉपी करो |
| कार्ड का रंग / emoji | `color: "blue"` और `icon: "🎮"` बदलो |
| कार्ड पूरी चौड़ाई में चाहिए | `wide: true,` |

एक छुपा हुआ नया कार्ड ऐसा दिखता है (सब गतिविधियों में हैं):
```
{
  hidden: true, icon: "⭐", color: "blue",
  title: { hi: "नया कार्ड 1", en: "New card 1" },
  list: [
    { hi: "यहाँ पहला बिंदु लिखें।", en: "Write the first point here." }
  ]
},
```
चारों गतिविधि पेज पर कार्ड हमेशा उसी क्रम में, बराबर कतारों में साफ़ सजे दिखते हैं (जिस क्रम में आपने `data.js` में लिखे). **संपर्क का डिब्बा हमेशा सबसे आख़िर में** आता है, अकेला। यात्रा संघ में अभी सब कार्ड छुपे हैं, इसलिए "जल्द आ रहा है" दिखता है। उसका पेज बनाने के लिए `comingSoon: false,` करो, पोस्टर डालो, और जो कार्ड चाहिए उनसे `hidden: true,` मिटाकर टेक्स्ट लिखो। (क्रिकेट क्लब का पोस्टर और जानकारी भरी जा चुकी है।)

**नई गतिविधि जोड़ना (हर गतिविधि का अपना पेज बनता है):**
1. GitHub में रिपॉज़िटरी के पहले पेज पर किसी गतिविधि की फ़ाइल खोलो, जैसे `kids-club.html`. उसका सारा टेक्स्ट कॉपी करो।
2. **Add file → Create new file** दबाओ। नाम वाले डिब्बे में नई फ़ाइल का नाम लिखो, जैसे `yoga-club.html` (English छोटे अक्षर, बिना space). कॉपी किया हुआ टेक्स्ट पेस्ट करो।
3. उस टेक्स्ट में `data-activity="kids-club"` ढूँढो और `kids-club` की जगह नई `id` लिखो, जैसे `data-activity="yoga-club"`. Commit करो।
4. `data.js` में `window.ACTIVITIES` के किसी पूरे `{ ... },` डिब्बे को कॉपी करके आख़िरी डिब्बे के बाद पेस्ट करो। उसमें `id: "yoga-club"` और `page: "yoga-club.html"` लिखो, बाक़ी टेक्स्ट बदलो। `id` बाक़ी गतिविधियों से अलग रखो। Commit करो।

**हटाना या छुपाना:** डिब्बा मिटा दो, या उसमें `hidden: true,` लिख दो। सारी गतिविधियाँ हटाओ या छुपाओ तो "गतिविधियाँ" मेन्यू अपने आप ग़ायब हो जाता है।

**मेन्यू का नाम बदलना** ("गतिविधियाँ" की जगह जैसे "समुदाय"): `js/i18n.js` में `nav.activities` ढूँढो और हिंदी व English दोनों जगह बदलो (भाग 5.19).

> अगर `data.js` में `window.ACTIVITIES` न हो तो मेन्यू में यह हिस्सा नहीं दिखता, बाक़ी वेबसाइट सही चलती है।

### 5.21 सुविधाएँ (भोजनशाला आदि) और Home का सुविधा कार्ड

ऊपर के मेन्यू में **"मंदिर"** के अंदर **"सुविधाएँ"** का अपना पेज है। हर सुविधा का एक रंगीन कार्ड बनता है। सब **`window.SUVIDHA`** में है। अभी **भोजनशाला** भरी हुई है (शुद्ध भोजन, कूपन राशि, संपर्क)। उसके नीचे 3 छुपे हुए "नई सुविधा" कार्ड रखे हैं।

| लाइन | मतलब |
|---|---|
| `id` | छोटा नाम, English छोटे अक्षर |
| `pinned: true,` | Home पर "दान करें" और "मंदिर आइए" के साथ इसका एक छोटा कार्ड भी दिखे। एक या दो सुविधाओं पर ही लगाओ। न चाहिए तो यह लाइन मिटा दो |
| `icon`, `color` | एक emoji, और रंग (`orange`, `blue`, `purple`, `green`, `pink`, `gold`, `teal`) |
| `title` | सुविधा का नाम (हिंदी, English) |
| `short` | एक लाइन, Home के कार्ड में यही दिखती है |
| `paragraphs` | पेज का टेक्स्ट। हर अनुच्छेद `{ hi: "...", en: "..." },` |
| `info` | छोटी जानकारी की पंक्तियाँ, जैसे कूपन राशि: `{ icon: "🎟️", label: { hi: "कूपन राशि", en: "Coupon amount" }, value: { hi: "₹100", en: "₹100" } },` |
| `list` | बिंदुओं की सूची |
| `contactNote` | संपर्क वाली एक लाइन |
| `contacts` | किससे बात करें: `{ name: { hi: "नीरज जैन", en: "Neeraj Jain" }, role: { hi: "पुजारी", en: "Pujari" }, phone: "8770979624" },` (नंबर पर दबाने से कॉल लगता है) |

- **नई सुविधा जोड़ना:** छुपे "नई सुविधा" कार्ड से `hidden: true,` मिटाओ और टेक्स्ट बदलो। या किसी पूरे `{ ... },` डिब्बे को कॉपी करके आख़िर में पेस्ट करो।
- **बदलना (जैसे कूपन राशि या संपर्क):** उसी डिब्बे में `value` या `phone` बदलो।
- **छुपाना:** डिब्बे में `hidden: true,`. **हटाना:** डिब्बा मिटा दो। हर `info`, `list` और `contacts` की पंक्ति में भी `hidden: true,` चलता है।
- मेन्यू का नाम "सुविधाएँ" बदलना हो तो `js/i18n.js` में `nav.suvidha`, और Home के बटन का शब्द `home.suvidha_btn` (भाग 5.19).

### 5.22 Home का ऊपरी बैनर (Theme 2): लाइन, बटन, भगवान की फ़ोटो, णमोकार, पंखुड़ियाँ

`window.SITE` में ये लाइनें हैं (सब `js/data.js` में, `heroLine` ढूँढो):

| लाइन | क्या करती है |
|---|---|
| `name`, `place` | बैनर में बड़ा नाम (`name`) और उसके नीचे सुनहरा "नेमिधाम" (`place`) |
| `heroLine` | "नेमिधाम" के नीचे और बटनों के ऊपर की लाइन: `{ hi: "...", en: "..." }`. अभी: "जैन संस्कारों के बीजारोपण का एक नया केंद्र" / "A New Center for the Sowing of Jain Values" |
| `heroInvocation` | सबसे ऊपर की छोटी लाइन ("॥ जय जिनेन्द्र ॥"). न चाहिए तो `{ hi: "", en: "" }` |
| `heroButtons` | नीचे के दो बटन। हर बटन: `href` (किस पेज पर जाए), `label` (नाम), `style` (`"gold"` सुनहरा या `"ghost"` हल्का)। बटन हटाना हो तो पूरी लाइन `{ ... },` मिटा दो, या `href: ""` कर दो |
| `heroPetals` | `true` = उड़ती पंखुड़ियाँ और कमल, `false` = बंद |
| `murti` | भगवान नेमिनाथ की फ़ोटो का रास्ता, अभी `"images/neminath.webp"` (हल्की फ़ाइल, जल्दी खुलती है; `neminath.png` बैकअप के तौर पर रखी है) |
| `mantraLines` | भगवान के नीचे चलती णमोकार की पट्टी। हर लाइन एक quote में, जितनी चाहो |

**भगवान नेमिनाथ की फ़ोटो लगाना:** फ़ोटो ऐसी हो जिसका पीछे का हिस्सा पारदर्शी (transparent PNG) हो, ताकि पीछे का भामंडल दिखे। उसका नाम `neminath.png` रखकर `images` फ़ोल्डर में अपलोड करो (भाग 4)। जब तक फ़ोटो नहीं है, एक सुनहरी आकृति दिखती है। दूसरा नाम रखना हो तो `murti:` में वही नाम लिखो।

### 5.23 दैनिक कार्यक्रम (रोज़ का क्रम और तारीख़ का कैलेंडर)

पेज: मेन्यू → कार्यक्रम → दैनिक कार्यक्रम। `window.DAILY` ढूँढो। हर लाइन दिन का एक काम है:

| लाइन | क्या लिखना है |
|---|---|
| `at` | `"open"` (पट खुलना), `"abhishek"`, `"aarti"`, `"close"`: इनका समय `window.SITE` → `timings` से अपने आप आता है (भाग 5.5), इसलिए दो जगह नहीं लिखना |
| `time` | दूसरे कामों का अपना समय, 24 घंटे वाला, जैसे `"08:30"` (`at` की जगह) |
| `icon` | छोटा चिह्न (emoji) |
| `title`, `text` | नाम और एक लाइन (हिंदी, English) |

क्रम अपने आप समय के हिसाब से लगता है। शांतिधारा (08:30) और पूजा (09:30) के समय अभी **SAMPLE** हैं, असली समय लिखो। नया काम जोड़ने के लिए एक पूरी लाइन कॉपी करो (भाग 2.3). पेज पर महीने का कैलेंडर है: किसी भी बीती या आने वाली तारीख़ पर दबाओ तो उस दिन का क्रम, कार्यक्रम (`window.EVENTS`) और जैन तिथि (`window.CALENDAR`) दिखती है। जिस तारीख़ पर कुछ ख़ास है उस पर छोटा बिंदु रहता है।

### 5.24 टाइमलाइन (मंदिर का सफ़र): जोड़ना, हटाना, छुपाना, फ़ोटो

पेज: मेन्यू → हमारे बारे में → टाइमलाइन। `js/data.js` में `window.TIMELINE` ढूँढो।

**हर घटना (entry) एक अलग डिब्बा है और डिब्बे बारी-बारी से बाएँ और दाएँ दिखते हैं।** एक ही साल (जैसे 2024) की दो घटनाएँ (मार्च और अगस्त) भी अलग-अलग तरफ़ आती हैं।

**हर घटना में क्या-क्या लिख सकते हो:**

| लाइन | क्या लिखना है |
|---|---|
| `year` | साल, जैसे `"2024"` (डिब्बे पर बड़ा दिखता है) |
| `when` | (वैकल्पिक) महीना या तारीख़, `{ hi: "मार्च", en: "March" }`. न चाहिए तो यह लाइन मिटा दो |
| `title`, `text` | नाम और विवरण (हिंदी और English). `text` खाली रख सकते हो |
| `photo` | (वैकल्पिक) एक फ़ोटो, जैसे `"images/timeline/bhumi.jpg"` |
| `photos` | (वैकल्पिक) कई फ़ोटो: `["images/timeline/a.jpg", "images/timeline/b.jpg"]` |
| `hidePhoto: true,` | फ़ोटो **छुपाने** के लिए (फ़ाइल और लिखा हुआ पता वहीं रहता है, बाद में लाइन मिटाकर फिर दिखा सकते हो) |
| `hidden: true,` | पूरी घटना **छुपाने** के लिए |

**नई घटना जोड़ना:** किसी एक पूरी लाइन `{ year: ..., ... },` को कॉपी करो, उसी सूची में कहीं भी पेस्ट करो (कॉमा `,` अंत में रहे) और टेक्स्ट बदलो। घटनाएँ फ़ाइल के क्रम में दिखती हैं, इसलिए पुरानी से नई की तरफ़ (ऊपर से नीचे) लिखो।
**घटना हटाना:** उसकी पूरी `{ ... },` लाइन मिटा दो। **बिना मिटाए छुपाना:** उसमें `hidden: true,` लिख दो।
**घटना बदलना:** `year`, `when`, `title`, `text` में जो चाहिए बदलो।

**फ़ोटो कैसे जोड़ें (स्टेप):**
1. फ़ोटो पहले छोटी करो (भाग 4: चौड़ाई लगभग 1200 px, JPG, 300 KB तक)।
2. GitHub में `images/timeline/` फ़ोल्डर खोलो (नहीं हो तो बना लो) और फ़ोटो अपलोड करो। फ़ाइल का नाम अंग्रेज़ी में, बिना स्पेस, जैसे `bhumi-daan.jpg`.
3. उसी घटना में एक लाइन जोड़ो: `photo: "images/timeline/bhumi-daan.jpg",` (एक फ़ोटो) या `photos: ["images/timeline/a.jpg", "images/timeline/b.jpg"],` (कई फ़ोटो)।
4. Commit करो। फ़ोटो पर क्लिक करने से बड़ी खुलती है।

**फ़ोटो छुपाना:** घटना में `hidePhoto: true,` लिखो। **फ़ोटो हटाना:** `photo: "",` या `photos: [],` कर दो (या वह लाइन मिटा दो), और चाहो तो फ़ाइल भी `images/timeline/` से हटा दो।
**पूरा टाइमलाइन पेज मेन्यू से हटाना:** `window.SITE` → `hideMenu: ["timeline"]` (भाग 5.26)। अभी की सारी घटनाएँ **SAMPLE** हैं, असली लिखकर बदलो।

### 5.25 दर्शन पेज और मंदिर नियम

"दर्शन" पेज में 4 टैब हैं: दर्शन का समय, कैसे पहुँचें (पता, नक्शा, रास्ता), सुविधाएँ (`window.SUVIDHA`, भाग 5.21), मंदिर नियम। **मंदिर नियम** `window.MANDIR_NIYAM` में हैं:
```
window.MANDIR_NIYAM = {
  intro: { hi: "...", en: "..." },      // ऊपर की एक लाइन
  list: [ { hi: "...", en: "..." }, ... ]   // हर नियम एक लाइन
};
```
नियम जोड़ना, बदलना, हटाना भाग 2.3 जैसा। टैब का नाम बदलना हो तो `i18n.js` में `v.tab_dress` (हिंदी: "मंदिर नियम", English: "Mandir rules").

### 5.29 आस-पास (मंदिर, तीर्थ, घूमने की जगहें): बटन वाला पेज

पेज: मेन्यू → दर्शन → आस-पास (`nearby.html`)। इस पेज पर ऊपर **बटन (टैब)** हैं, जैसे "दर्शन" पेज पर होते हैं। जिस बटन को दबाओ, सिर्फ़ उसी के कार्ड दिखते हैं। अभी 3 बटन हैं: **आस-पास के मंदिर**, **आस-पास के तीर्थ क्षेत्र**, **घूमने की जगहें**. एक चौथा बटन (`extra`, "और जगहें") छुपा हुआ तैयार रखा है।

`js/data.js` में `window.NEARBY` ढूँढो। इसमें बड़े डिब्बे (group) हैं, हर group = एक बटन। हर group के अंदर `items: [ ... ]` में कार्ड हैं।

**group की लाइनें (बटन के बारे में):**

| लाइन | क्या करती है |
|---|---|
| `id` | बटन की पहचान। अंग्रेज़ी में, छोटा, बिना स्पेस, जैसे `"hotels"` (हर group का अलग) |
| `icon` | बटन के आगे एक emoji |
| `title` | बटन का नाम `{ hi: "...", en: "..." }`. छोटा रखो, ताकि बटन में आ जाए |
| `intro` | (वैकल्पिक) कार्डों के ऊपर एक लाइन। न चाहिए तो `{ hi: "", en: "" }` |
| `hidden: true,` | **पूरा बटन छुपाने** के लिए |

**कार्ड की लाइनें (हर मंदिर, तीर्थ या जगह के बारे में):**

| लाइन | क्या लिखना है |
|---|---|
| `name` | नाम `{ hi: "...", en: "..." }` |
| `distance` | दूरी, जैसे `{ hi: "5 किमी", en: "5 km" }` |
| `address` | पता `{ hi, en }` |
| `text` | छोटा विवरण `{ hi, en }` (खाली छोड़ सकते हो) |
| `phone` | फ़ोन `"9876543210"`. कई नंबर हों तो कॉमा से: `"98..., 97..."`. दबाने पर कॉल लगता है |
| `mapLink` | "नक्शे में देखें" बटन के लिए Google Maps का लिंक। या `mapQuery: "नाम, शहर"` लिखो। न चाहिए तो `""` |
| `photo` / `photos` | फ़ोटो: `photo: "images/nearby/naam.jpg"` या `photos: ["images/nearby/a.jpg", "images/nearby/b.jpg"]` |
| `hidePhoto: true,` | **फ़ोटो छुपी रहेगी।** अभी हर कार्ड में यह लाइन है, यानी फ़ोटो by default छुपी है। फ़ोटो दिखानी हो तो यह लाइन **मिटा दो** |
| `hidden: true,` | **पूरा कार्ड छुपाने** के लिए |

**कार्ड जोड़ना (नया मंदिर, नई जगह):**
1. उसी group के किसी एक पूरे कार्ड `{ ... },` को कॉपी करो।
2. उसी group की `items` सूची में नीचे पेस्ट करो (हर कार्ड के बाद कॉमा `,` रहे)।
3. नाम, पता, फ़ोन वगैरह बदलो। (हर group में 2-3 ख़ाली कार्ड `hidden: true,` के साथ तैयार हैं। उनसे `hidden: true,` मिटा दो तो वे दिखने लगते हैं, अलग से कॉपी की ज़रूरत नहीं।)

**कार्ड हटाना:** उसकी पूरी `{ ... },` मिटा दो। **बिना मिटाए छुपाना:** `hidden: true,`.

**फ़ोटो जोड़ने के स्टेप:**
1. फ़ोटो छोटी करो (भाग 4, चौड़ाई लगभग 1200 px, 300 KB तक)।
2. GitHub में `images/nearby/` फ़ोल्डर में अपलोड करो। नाम अंग्रेज़ी में, बिना स्पेस, जैसे `shanti-mandir.jpg`.
3. कार्ड में `photos: ["images/nearby/shanti-mandir.jpg"],` लिखो।
4. उसी कार्ड से `hidePhoto: true,` मिटा दो। Commit करो।
5. फ़ोटो फिर छुपानी हो तो `hidePhoto: true,` वापस लिख दो। हमेशा के लिए हटानी हो तो `photos: [],` कर दो।

**नया बटन बनाना (जैसे "भोजनालय" या "होटल"):** `window.NEARBY` में किसी एक पूरे group `{ id: ..., items: [ ... ] },` को कॉपी करो, उसी सूची में पेस्ट करो, `id` नई (किसी और group जैसी नहीं) रखो और `title`, कार्ड बदलो। बटन अपने आप बन जाता है। `hidden: true,` वाला spare group (`extra`) भी इस्तेमाल कर सकते हो।
**बटन हटाना:** पूरा group मिटा दो, या छुपाने के लिए `hidden: true,`.
**पूरा आस-पास पेज मेन्यू से हटाना:** `window.SITE` → `hideMenu: ["nearby"]` (भाग 5.26)।
**शब्द बदलना:** पेज का शीर्षक और उप-शीर्षक `i18n.js` में `p.nearby.h1`, `p.nearby.lead`; मेन्यू का नाम `nav.nearby` ("आस-पास"); कार्ड के बटन `nb.map` ("नक्शे में देखें"), `nb.dist` ("दूरी").
**एक सीधा लिंक:** किसी बटन पर सीधे खुलने वाला लिंक: `nearby.html#tourist` (अपने group की `id` लिखो)।
अभी की सारी एंट्री **SAMPLE** हैं, असली नाम, पता और नंबर लिखो।

### 5.26 मेन्यू: कुछ छुपाना

मेन्यू का ढाँचा तय है: होम, योजनाएं, कार्यक्रम ▾, (गतिविधियाँ ▾), गैलरी ▾, हमारे बारे में ▾, दर्शन ▾, दान। `window.SITE` में:

- `hideMenu: ["timeline"],` : जो पेज मेन्यू में न चाहिए उनके नाम लिखो (`"yojana"`, `"daily"`, `"karyakram"`, `"calendar"`, `"announcements"`, `"gallery"`, `"about"`, `"timeline"`, `"team"`, `"visit"`, `"nearby"`, `"daan"`). एक से ज़्यादा हों तो कॉमा से अलग करो। पेज ख़ुद बना रहता है, बस मेन्यू से हटता है।
- `hideHome: ["notices"],` : **Home पेज** के हिस्से छुपाने के लिए। नाम: `"yojana"` (योजनाएं), `"notices"` (सूचनाएं), `"events"` (कार्यक्रम), `"gallery"` (फ़ोटो पट्टी), `"cta"` (नीचे के दान और दर्शन के दो कार्ड). बाक़ी हिस्सों के पीछे का रंग अपने आप बारी-बारी से सही रहता है।
- `hideVisitTabs: ["rules"],` : "दर्शन" पेज के टैब छुपाने के लिए: `"timings"`, `"reach"`, `"facilities"`, `"rules"`.
- `dharmshalaSoon: false,` : "हमारे बारे में" में धूसर "धर्मशाला (जल्द)" लाइन हटाने के लिए।
- मेन्यू के शब्द: `i18n.js` में `nav.*` (भाग 5.19).

### 5.27 रंग, अक्षर और चलती चीज़ें (Theme 2)

- **अक्षर (fonts):** Cinzel, Cormorant Garamond और Tiro Devanagari Hindi, ये Google Fonts से आते हैं। इसके लिए इंटरनेट चाहिए (वैसे भी वेबसाइट के लिए चाहिए)। न मिलें तो वेबसाइट सादे अक्षरों में ठीक दिखती है।
- **रंग:** `css/theme2.css` की शुरुआत में `:root { ... }` में सारे रंग एक जगह हैं (`--gold`, `--midnight`, `--paper`...)। यह कोड वाली फ़ाइल है, बदलना हो तो किसी जानकार से करवाओ।
- **चलती चीज़ें** (घूमता मंडल, भामंडल, पंखुड़ियाँ, णमोकार पट्टी): जिनके फ़ोन में "कम हलचल" (reduce motion) चालू है उनके लिए अपने आप रुक जाती हैं। पंखुड़ियाँ ख़ुद बंद करनी हों तो `heroPetals: false`.
- **Light / Dark / High contrast:** ऊपर के बटन से, अपने आप चलता है। High contrast में सारे अक्षर पूरे काले (या dark में पूरे सफ़ेद) हो जाते हैं।
- **पुराना रूप (Theme 1) वापस चाहिए:** Theme 1 वाली अलग zip अपलोड करो। (Theme 2 में उसकी जगह सिर्फ़ `theme2.css` की लाइन हर `.html` से हटाने से भी बहुत कुछ पुराना दिखेगा, पर पूरा नहीं; अलग zip सुरक्षित तरीक़ा है।)

**मंडल (mandala) की चित्रकारी:** हर पेज के पीछे हल्की, पतली लाइनों वाला मंडल है (कहीं आधा, कहीं पूरा)। यह फ़ाइल `images/mandala-section.svg` है। Home के ऊपरी बैनर, पेज के ऊपरी बैंगनी हिस्से और फुटर में पुराना `images/mandala.svg` चलता है। चित्र बदलना हो तो इसी नाम से नई SVG फ़ाइल अपलोड कर दो। इसे कम या ज़्यादा दिखाने के लिए `css/theme2.css` में सबसे नीचे `main::before` वाली लाइन में `opacity: .2` (0 = ग़ायब, 0.5 = गहरा) बदलो। Home के सेक्शन शीर्षक के पीछे वाला मंडल `.section-head::before` वाली लाइन में `opacity` से बदलता है।

### 5.28 अक्षर और रंग पढ़ने में आसान रहें (नियम)

- नई जानकारी लिखते समय बहुत लंबे वाक्य न लिखो; हर कार्ड की पहली लाइन छोटी रखो।
- फ़ोटो में अक्षर लिखे हों (पोस्टर) तो उन्हें इतना बड़ा रखो कि मोबाइल पर पढ़े जाएँ।
- सारे टेक्स्ट का रंग और आकार हर पेज पर जाँचा गया है (Light, Dark और High contrast में)। कोई अक्षर फिर भी हल्का या छोटा दिखे तो पेज और मोड बताकर बताओ।

### 5.30 Google में दिखना और WhatsApp का शेयर फ़ोटो (SEO)

**ये क्या है?** जब कोई वेबसाइट का लिंक WhatsApp/Facebook पर भेजता है तो एक फ़ोटो + नाम + छोटा विवरण दिखता है। ये `images/og-share.jpg` से आता है। Google के लिए `sitemap.xml` (सारे पेजों की सूची) और `robots.txt` बनी हैं।

**शेयर वाला फ़ोटो बदलना:** नया फ़ोटो 1200x630 साइज़ का बनाओ, नाम `og-share.jpg` रखो और `images` फ़ोल्डर में पुराने की जगह डाल दो। बस इतना ही।
**ध्यान दो:** WhatsApp पुराना फ़ोटो कुछ दिन याद रखता है। जल्दी बदलवाना हो तो Facebook का "Sharing Debugger" (developers.facebook.com/tools/debug) में लिंक डालकर "Scrape Again" दबाओ।

**हर पेज का टाइटल/विवरण बदलना:** उस पेज की `.html` फ़ाइल खोलो, ऊपर `<title>` और `description` वाली लाइनें हैं, सिर्फ़ उनका लिखा हुआ बदलो।

**अगर वेबसाइट का पता (लिंक) बदले** (जैसे अपना डोमेन लिया): सारी `.html` फ़ाइलों, `sitemap.xml` और `robots.txt` में `https://shenkisinghai.github.io/Nemidham/` ढूँढकर नए पते से बदल दो (Find & Replace से एक बार में हो जाता है)।

**Google Search Console में जोड़ना (ये आपको खुद करना है, एक बार):**
1. search.google.com/search-console खोलो और अपने Gmail से लॉगिन करो।
2. "Add property" में **URL prefix** चुनो और `https://shenkisinghai.github.io/Nemidham/` डालो।
3. Verify के लिए "HTML tag" तरीका चुनो। एक `<meta name="google-site-verification" ...>` लाइन मिलेगी, वो मुझे भेज दो, मैं `index.html` में डाल दूँगा। (या खुद `<head>` में डाल दो।)
4. फिर Verify दबाओ। बाईं तरफ़ "Sitemaps" में `sitemap.xml` लिखकर Submit करो।
5. Google को पेज दिखाने में कुछ दिन से 2 हफ़्ते लग सकते हैं। ये सामान्य है।

## 6. छुपाने / चालू करने (Hide / Enable) की सूची

| क्या छुपाना या चालू करना है | कैसे |
|---|---|
| सूचना, कार्यक्रम, योजना (और 4 ख़ाली योजना कार्ड), कैलेंडर की तारीख़, गैलरी एलबम, टीम का समूह, नियमित दान का कार्ड, हमारे बारे में का हिस्सा, कैसे पहुँचें का डिब्बा | उसके डिब्बे में `hidden: true,`. चालू करने के लिए वह लाइन मिटा दो |
| सुविधा (`window.SUVIDHA`) का कार्ड | उसके डिब्बे में `hidden: true,`. Home का कार्ड हटाना हो तो `pinned: true,` हटाओ |
| गतिविधियाँ मेन्यू की एक गतिविधि (`window.ACTIVITIES`) | उसके डिब्बे में `hidden: true,`. सब छुपाओ या मिटाओ तो पूरा मेन्यू अपने आप ग़ायब |
| योजना कार्ड पर Google Form बटन | उस कार्ड में `formUrl: ""` खाली कर दो |
| टीम का एक व्यक्ति | उसकी पूरी लाइन मिटा दो |
| ऊपर की सोने जैसी पट्टी | `window.BANNER` → `enabled: false` |
| आज के समय का डिब्बा | `window.SITE` → `showTimings: false` |
| Home की फ़ोटो पट्टी | `window.SITE` → `slideshow: { enabled: false, ... }` |
| पूरा दान पेज | `window.DAAN` → `enabled: false` (तब "जानकारी जल्द आएगी" दिखता है) |
| UPI / बैंक / "मंदिर कार्यालय" का कार्ड | उसकी जानकारी खाली `""` छोड़ दो |
| ट्रस्ट / 80G | `window.TRUST` → `enabled: false` |
| पुण्यार्जक या द्रव्य दान की तालिका | सूची खाली `[ ]` कर दो |
| Home पर कोई योजना / सूचना / कार्यक्रम | `pinned: true,` हटा दो |
| फुटर का "वेबसाइट संयोजक" | `credit: null` |
| विज़िटर की गिनती | `goatcounter: ""` |
| टाइमलाइन की घटना, दैनिक कार्यक्रम की एक लाइन (`window.TIMELINE`, `window.DAILY`) | उसके डिब्बे में `hidden: true,` |
| Home बैनर की उड़ती पंखुड़ियाँ / ऊपर की "जय जिनेन्द्र" लाइन | `heroPetals: false` / `heroInvocation: { hi: "", en: "" }` |
| मेन्यू का कोई पेज | `window.SITE` → `hideMenu: ["timeline"]` (भाग 5.26) |
| Home का कोई हिस्सा (योजनाएं, सूचनाएं, कार्यक्रम, फ़ोटो, दान/दर्शन कार्ड) | `window.SITE` → `hideHome: ["notices"]` (भाग 5.26) |
| "दर्शन" पेज का कोई टैब | `window.SITE` → `hideVisitTabs: ["rules"]` (भाग 5.26) |

## 7. अगर कुछ गड़बड़ दिखे

- **वेबसाइट खाली या आधी दिख रही है:** लगभग हमेशा `data.js` में कोई कॉमा `,` या quote `"` छूट गया होता है। अपनी वेबसाइट के पते के आख़िर में `/check.html` लगाकर खोलो। वह साफ़ भाषा में बताएगा कि क्या ग़लत है।
- **बदलाव दिख नहीं रहा:** 2 मिनट रुको और **Ctrl + Shift + R** दबाओ।
- **कुछ बिगड़ गया, पुराना वर्शन वापस लाना है:**
  1. GitHub में रिपॉज़िटरी का पहला पेज खोलो और ऊपर **Commits** (घड़ी का निशान) दबाओ।
  2. वहाँ हर बदलाव की सूची है: किसने, कब, क्या बदला।
  3. जिस बदलाव ने गड़बड़ की, उस पर क्लिक करो और **Revert** चुनो। पुराना सही रूप लौट आएगा।

## 9. नंबर (पिन कोड, राशि, फ़ोन) बड़े क्यों दिखते हैं

वेबसाइट अपने आप हर अंक (पिन कोड, ₹ राशि, फ़ोन और खाता नंबर) को आस-पास के अक्षरों जैसे ही फ़ॉन्ट में (मोटा किए बिना), थोड़ा बड़ा करके दिखाती है। आपको कुछ नहीं करना, बस `data.js` में सामान्य रूप से नंबर लिखो।
